# SistemaDeCadastroDeLivros

Este é um sistema de cadastro de livros desenvolvido em Windows Forms. Ele permite que os usuários adicionem, editem, removam e visualizem informações sobre livros em uma biblioteca. Além de poderem cadastrar novos autores para vincular aos livros.

# Funcionalidades
Adicionar Livros: Permite ao usuário adicionar novos livros.
Adicionar Autores: Permite ao usuário adicionar novos autores.
Editar Livros: Permite ao usuário editar informações de livros existentes.
Remover Livros: Permite ao usuário remover livros do sistema.
Visualizar Livros: Permite ao usuário visualizar uma lista de todos os livros cadastrados.
Buscar pelo título de Livros: Permite ao usuário que busque livros específicos dentre os já cadastrados no sistema pelo título.

# Tecnologias Aplicadas

Linguagem de Programação: C#
Plataforma: .NET Framework
Interface Gráfica: Windows Forms
Banco de Dados: MySQL
